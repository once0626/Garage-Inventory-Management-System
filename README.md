# 🚗 THE CAR HOME – Garage Inventory Management System

A modern and interactive inventory management system built using **Flask** and **SQLAlchemy**, designed specifically for car garages to manage parts, track stock, and monitor inventory efficiently.

---

## 🔥 Features

* 📦 Add and manage garage parts (with company & category)
* 🔄 Real-time stock update (IN / OUT system)
* ⚠️ Automatic low stock detection (≤ 5 items)
* 📜 Stock history tracking with timestamps
* 📊 Dashboard analytics:

  * Total Parts
  * Low Stock Items
  * Total Cost Value
  * Total Selling Value
* ❌ Soft delete (remove unused parts safely)
* 🎨 Clean and interactive UI (modern dark theme)
* ⚡ Fully dynamic system using Flask + SQLite

---

## 🛠️ Tech Stack

* **Backend:** Flask (Python)
* **Database:** SQLite (SQLAlchemy ORM)
* **Frontend:** HTML, CSS, JavaScript
* **UI:** Custom responsive dashboard

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/the-car-home-inventory.git
cd the-car-home-inventory
```

### 2️⃣ Install dependencies

```bash
pip install flask flask_sqlalchemy
```

### 3️⃣ Run the application

```bash
python app.py
```

### 4️⃣ Open in browser

```
http://127.0.0.1:5000
```
